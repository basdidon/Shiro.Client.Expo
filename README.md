# Shiro.Client.Expo

A mobile client for the Shiro inventory/POS system, built with [Expo](https://expo.dev) and React Native. It provides authentication, product & category management, barcode scanning, orders/checkout, a dashboard, and user management against a Shiro backend API.

## Features

- **Auth** — login/register screens backed by secure token storage
- **Products & Categories** — list, create, and manage products and categories
- **Barcode scanner** — scan product barcodes via `expo-camera`
- **Cart & Orders** — cart flow, checkout, and order history/detail views
- **Dashboard** — summary view for store activity
- **Users** — user list/detail management
- Typed API client generated from the backend's OpenAPI spec

## Tech stack

- [Expo](https://docs.expo.dev/versions/v57.0.0/) (SDK 57) + [Expo Router](https://docs.expo.dev/router/introduction) (file-based, typed routes)
- React 19 / React Native 0.86
- [TanStack Query](https://tanstack.com/query) for server state
- [Zustand](https://github.com/pmndrs/zustand) for client state
- [react-hook-form](https://react-hook-form.com/) + [Zod](https://zod.dev/) for form handling & validation
- [openapi-fetch](https://openapi-ts.dev/openapi-fetch/) with types generated by `openapi-typescript`
- TypeScript, ESLint (`eslint-config-expo`)

> This project targets Expo SDK 57, which changed significantly from earlier SDKs. Consult the versioned docs at https://docs.expo.dev/versions/v57.0.0/ before making changes.

## Get started

1. Install dependencies

   ```bash
   npm install
   ```

2. Start the app

   ```bash
   npx expo start
   ```

In the output, you'll find options to open the app in a

- [development build](https://docs.expo.dev/develop/development-builds/introduction/)
- [Android emulator](https://docs.expo.dev/workflow/android-studio-emulator/)
- [iOS simulator](https://docs.expo.dev/workflow/ios-simulator/)
- [Expo Go](https://expo.dev/go), a limited sandbox for trying out app development with Expo

Routing and screens live under [src/app](src/app), using Expo Router's file-based routing.

## Project structure

```
src/
  app/          Expo Router routes (tabs, cart, categories, orders, products, users, auth)
  api/          API modules per resource (categories, checkouts, dashboard, orders, products, users)
  components/   Shared UI components
  hooks/        Custom hooks
  lib/          Utilities and validation schemas
  screens/      Screen-level components
  store/        Zustand stores
  types/        Shared/generated types (incl. api.d.ts from OpenAPI)
```

## Scripts

| Script | Description |
| --- | --- |
| `npm start` | Start the Expo dev server |
| `npm run android` | Start the dev server and open on Android |
| `npm run ios` | Start the dev server and open on iOS |
| `npm run web` | Start the dev server and open on web |
| `npm run lint` | Run ESLint via `expo lint` |
| `npm run gen:api` | Regenerate `src/types/api.d.ts` from the backend's OpenAPI schema at `http://localhost:5000/openapi/v1.json` |
